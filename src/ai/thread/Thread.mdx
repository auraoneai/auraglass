## Using with the Vercel AI SDK

`useChat()` from `@ai-sdk/react` returns messages already assignable to
`AgMessage` — pass them straight through:

```tsx
const { messages, sendMessage, status } = useChat();
<Thread messages={messages} streaming={status === 'streaming'} />
```

## Routing models through Kiro Prism

The library makes no model call itself — see the `ai-workspace` registry block
and `apps/docs/content/surf/ai-prism-routing.md` for the reference route
(`createOpenAICompatible` against `https://prism.auraone.ai/v1`).
