# Thread

Scroll-pinned message log: virtualizes after `virtualizeAfter` rows, keeps the last message pinned while streaming, and jumps back with an announced button when the reader scrolls up.

`<Thread messages={…} />` renders `<Thread.Root><Thread.Viewport><Thread.Items /></Thread.Viewport></Thread.Root>`.
`Thread.Viewport` is the single `role="log"` scroll container (virtualized rows scroll inside it, never in a nested scroller);
compose the parts yourself to add content around the log. The JumpToLatest pill's accessible name is its visible text.

## Using with the Vercel AI SDK

`useChat()` from `@ai-sdk/react` returns messages already assignable to
`AgMessage` — pass them straight through:

```tsx
const { messages, sendMessage, status } = useChat();
<Thread messages={messages} streaming={status === 'streaming'} />
```
