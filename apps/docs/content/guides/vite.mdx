# Vite

AuraGlass works in any Vite + React app (client-side rendering). Requires `aura-glass@^5`, React 19 and Node 20.19 or later. For a scaffold-to-running walkthrough see the Vite quickstart.

## 1. Install

```bash
npm install aura-glass@^5
```

`npx @auraglass/cli init` installs the package and writes the stylesheet import for you.

## 2. Stylesheet and provider

Import the stylesheet once, **before** your own CSS, and wrap the app in `AuraGlassProvider`:

```tsx
// src/main.tsx
import 'aura-glass/styles.css';
import './index.css';
import { StrictMode } from 'react';
import { createRoot } from 'react-dom/client';
import { AuraGlassProvider } from 'aura-glass/theme';
import { App } from './App';

createRoot(document.getElementById('root')!).render(
  <StrictMode>
    <AuraGlassProvider>
      <App />
    </AuraGlassProvider>
  </StrictMode>,
);
```

All AuraGlass CSS sits in `ag.*` cascade layers, so the unlayered rules in `index.css` override it without `!important` (see the Plain CSS guide). With Tailwind v4 use the stylesheet setup from the Tailwind guide instead of the bare import.

## 3. Pre-paint script

The provider applies the user's stored preferences (scheme, transparency, contrast, motion) when React mounts. To apply them before the first paint, put the pre-paint routine inline in `index.html`'s `<head>`. `aura-glass/theme` exports it as a string, `auraGlassPrepaintScript`; a small Vite plugin inlines it at build and dev time:

```ts
// vite.config.ts
import { defineConfig, type Plugin } from 'vite';
import react from '@vitejs/plugin-react';
import { auraGlassPrepaintScript } from 'aura-glass/theme';

const auraGlassPrepaint = (): Plugin => ({
  name: 'auraglass-prepaint',
  transformIndexHtml: () => [
    { tag: 'script', children: auraGlassPrepaintScript, injectTo: 'head-prepend' },
  ],
});

export default defineConfig({ plugins: [react(), auraGlassPrepaint()] });
```

The string runs the routine with the default storage key and no defaults: it restores what the user chose earlier. Values you pass as provider props apply when React mounts. With a Content Security Policy, allow the inline script by hash or nonce.

## 4. Use components

```tsx
// src/App.tsx
import { Button, Card } from 'aura-glass';

export function App() {
  return (
    <Card>
      <Button onClick={() => console.log('saved')}>Save</Button>
    </Card>
  );
}
```

No Vite configuration is needed for the package itself: it ships compiled ES modules with an `exports` map, and `optimizeDeps` pre-bundles it like any other dependency.
