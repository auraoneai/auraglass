# API index

Public API is generated from `build/exports.manifest.json` and the packed
`.d.ts` (gen-component-docs.mjs, TypeScript compiler API). Only exported
symbols get pages — internal helpers never surface. Each component's
agent-facing reference is also published as `/components/<slug>.md`.

- [Registry index](/plat/registry) — every published block/item
- Deprecations — see the [v5 migration guide](/plat/migrate/5)
