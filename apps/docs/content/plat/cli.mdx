# CLI

`aura-glass-cli` sets AuraGlass up in your app and installs registry
items into it.

```bash
npx aura-glass-cli init       # writes auraglass.json + the stylesheet imports
npx aura-glass-cli add auth   # installs the auth block
```

`init` is idempotent; `add` writes the item's files under `components/` and
declares its dependencies. See the quickstarts for the full path.
