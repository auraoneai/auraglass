# Introduction

AuraGlass 5.0 is the glass-native component system: CMP components, MAT
material seams, SURF surfaces, and a PLAT registry that publishes them as
shadcn-format items.

- Install: `npx @auraglass/cli init` in a Next 16 or Vite app.
- Add a block: `npx @auraglass/cli add <name>` (see the [registry index](/plat/registry)).
- Claims on this site are sourced from build artifacts; values that have not
  shipped yet render **pending**, never invented numbers.
