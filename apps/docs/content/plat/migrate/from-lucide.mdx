# Migrating From Lucide To AuraGlass Icons

AuraGlass keeps core app chrome on first-party icons. The goal is that product surfaces can use `aura-glass` without adding `lucide-react` for common controls, navigation, status, media, data, commerce, collaboration, or AI symbols.

## Install Shape

Core UI should only need AuraGlass:

```bash
npm install aura-glass
```

Then import icons from the public icon entrypoint:

```tsx
import { Button } from 'aura-glass';
import { SearchIcon, SettingsIcon, SparkIcon } from 'aura-glass/icons';

export function Toolbar() {
  return (
    <div>
      <Button startIcon={<SparkIcon aria-hidden="true" />}>Generate</Button>
      <SearchIcon aria-hidden="true" />
      <SettingsIcon title="Settings" />
    </div>
  );
}
```

## Before And After

Before:

```tsx
import { Search, Settings, X } from 'lucide-react';

export function HeaderActions() {
  return (
    <>
      <Search aria-hidden="true" />
      <Settings aria-hidden="true" />
      <X aria-hidden="true" />
    </>
  );
}
```

After:

```tsx
import { CloseIcon, SearchIcon, SettingsIcon } from 'aura-glass/icons';

export function HeaderActions() {
  return (
    <>
      <SearchIcon aria-hidden="true" />
      <SettingsIcon aria-hidden="true" />
      <CloseIcon aria-hidden="true" />
    </>
  );
}
```

## CLI Assistance

Use the migration command in report mode first (it reports until you pass `--write`):

```bash
npx aura-glass-cli migrate icons --from lucide
npx aura-glass-cli migrate icons --from lucide --json
```

Apply the import-source rewrites with:

```bash
npx aura-glass-cli migrate icons --from lucide --write
```

The rewrite only changes the module specifier (`lucide-react` → `aura-glass/icons`); it does not rename the imported symbols. Rename them yourself — aliasing the AuraGlass icon names back to the existing local component names keeps JSX usage stable during the first pass:

```tsx
import { SearchIcon as Search, CloseIcon as X } from 'aura-glass/icons';
```

After the app compiles, rename local JSX usages to the canonical `*Icon` names where useful.

## Accessibility

Decorative icons should keep `aria-hidden="true"`. Icons that are the only visible label for an action need an accessible name on the button, not only on the icon:

```tsx {fragment}
import { SearchIcon } from 'aura-glass/icons';

<button aria-label="Search">
  <SearchIcon aria-hidden="true" />
</button>
```

Use `title` only when the icon itself is meaningful content. Do not rely on hover titles as the only label for controls.

## Verification

Run these checks after migration:

```bash
npx aura-glass-cli audit imports
npx aura-glass-cli audit deps
```

The release target remains zero production imports from `lucide-react` in AuraGlass core app chrome.
