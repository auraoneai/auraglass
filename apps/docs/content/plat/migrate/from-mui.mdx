# Migrating From MUI To AuraGlass

AuraGlass is not trying to clone all of MUI. The target is core app chrome for premium dashboards, AI products, SaaS admin surfaces, media workspaces, ecommerce panels, and collaboration hubs without adding `@mui/material` or `@mui/icons-material`.

## Replacement Map

| MUI job | AuraGlass replacement |
| --- | --- |
| `Button` | `Button` |
| `IconButton` | `IconButton` (icons from `aura-glass/icons`) |
| `Card` | `Card` |
| `AppBar` / `Toolbar` | `TopBar`, `Toolbar`, `AppShell` (from `aura-glass/app-shell`) |
| `Drawer` | `Sheet` |
| `Dialog` | `Dialog` |
| `Menu` | `Menu`, `Menubar` |
| `Select` | `Select` |
| `Tabs` | `Tabs`, `TabBar` |
| `Tooltip` | `Tooltip` |
| `Popover` | `Popover` |
| `TextField` | `TextField` (`multiline` for textarea), `Form` |
| `Checkbox` | `Checkbox` |
| `RadioGroup` | `RadioGroup` |
| `Switch` | `Switch` |
| `Alert` | `Alert`, `Toast` |
| `Chip` | `Chip` (from `aura-glass/data`) |
| `Avatar` | `Avatar` |
| `Pagination` | `Pagination` |
| `Skeleton` | `Skeleton` |
| table basics | the `aura-glass/data` table surface |
| date/calendar basics | `Calendar`, `DateRangePicker` (from `aura-glass/date`) |

## Before And After

Before:

```tsx
import { AppBar, Box, Button, Toolbar } from '@mui/material';

export function BillingHeader() {
  return (
    <AppBar position="static">
      <Toolbar>
        <Box sx={{ flex: 1 }}>Billing</Box>
        <Button variant="contained">Upgrade</Button>
      </Toolbar>
    </AppBar>
  );
}
```

After:

```tsx
import { Button } from 'aura-glass';
import { TopBar } from 'aura-glass/app-shell';

export function BillingHeader() {
  return (
    <TopBar.Root>
      <TopBar.Title>Billing</TopBar.Title>
      <TopBar.Trailing>
        <Button>Upgrade</Button>
      </TopBar.Trailing>
    </TopBar.Root>
  );
}
```

## Theme Migration

Move brand, density, contrast, and motion decisions into AuraGlass theme tokens instead of `createTheme` overrides. Keep domain-specific data and business state outside the theme layer.

Use [Plain CSS → Redefining tokens](/guides/plain-css#redefining-tokens) to carry brand values over as AuraGlass token overrides.

## CLI Audit

MUI migration is report-first because layout and component semantics are contextual:

```bash
npx aura-glass-cli migrate mui
npx aura-glass-cli migrate mui --json
npx aura-glass-cli audit deps
npx aura-glass-cli audit imports
```

## Verification

Run these checks after migration:

```bash
npx aura-glass-cli doctor
```

The release target is that AuraGlass core app chrome does not require MUI/material.
