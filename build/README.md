# build/ — AuraGlass 5.0 build stack (REQ-PLAT-64)

## Tool choice

The build is **tsdown (esbuild) + tsc emit pass**, driven by `scripts/build/`:

- `npm run build` = `tokens:build` → `tsdown` (js) → `tsc -p build/.tsconfig.emit.json` (d.ts) → `post.mjs` (css + exports manifest).
- One pass produces every artifact; a second pass into a parallel out dir is byte-identical (`tests/build/single-build.test.ts`).

## Rollup fallback trigger

Rollup is only reconsidered if esbuild cannot emit a required module shape
(e.g. a needed `preserveModules` behaviour it cannot express). Today no such
requirement exists — `rollup.config.js` and `bundlesize` are deleted from the
build path and must not be reintroduced without a decision record here.

## attw node10 decision

`attw --profile esm-only` is the export-surface checker. The `node10` profile
is intentionally not run: 5.0 is ESM-only with Node >=20.19 floor (B2), so
node10 CJS-resolution errors are expected and not defects.

## CSS baseline

`dist/styles.css` is the single shipped stylesheet, assembled by
`scripts/build/post.mjs` (layer order in `build/css-order.json`). The 4.x
compat sheet (`dist/styles/compat.css`) is generated by
`scripts/tokens/build.mjs` — the one writer allowed to touch it.

## esbuild confinement

esbuild may only run through the npm scripts (`tsdown` wraps it).
Direct esbuild entrypoints in `scripts/**` are rejected by
`tests/build/single-build.test.ts`.
