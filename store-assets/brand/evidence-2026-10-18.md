## Wiring (web surface with meta existed → wired)

`apps/docs` is a Next.js static-export docs site whose root layout already
exported `metadata`. Added there: `metadataBase` from the repo's tracked
`PUBLIC_DOCS_URL` (`scripts/docs/paths.mjs` → `https://auraglass-48859d.gitlab.io/`),
`openGraph` (1200×630 image + alt) and `twitter` (`summary_large_image`,
1200×600). Icons are wired by Next file conventions (`app/icon.png`,
`app/apple-icon.png`). Served copies live in `apps/docs/public/brand/`.

Live verification (dev server, 2026-10-18): homepage emitted
`og:image`/`twitter:image` with the absolute Pages URL, `og:image:width/
height/alt`, `<link rel=icon>` 512×512 and `<link rel=apple-touch-icon>`
180×180; `/brand/og-1200x630.png`, `/brand/twitter-1200x600.png` and
`/icon.png` all returned 200 with the exact byte sizes above.

Pre-existing build failure noted (not caused by this pass): `next build`
prerender of `/components/avatar` + `/components/select` fails identically
with and without these changes in this checkout (stale pack in
`apps/docs/node_modules`); wiring was verified via `next dev` instead.
