# 4.1.1 trust patch — deprecation seed exceptions (REQ-PLAT-55)

`release/4.1.x` is the patch-scope-clean line cut from `78fd7bda1` per OD-13.
Its deprecation seed is `since: '4.1.1'` — every entry below was announced in
the 4.1.1 trust patch rather than scheduled through the 4.x minor train, so
each carries a declared `exception` plus this record as evidence:

- **honesty** — DEP-P0001…P0011 (root-exported `reports/*` path constants),
  DEP-P0014 (ContrastGuard unconditional pass), DEP-P0018/P0019
  (`data-meets-wcag` / `data-contrast-ratio` attributes): public surface that
  claimed guarantees the package did not provide. Announcing them early is the
  point of the trust patch.
- **privacy** — DEP-P0012 (`enableAdaptiveAI` prop), DEP-P0016/P0017
  (`adaptiveAI`, `useAdaptiveAI`), DEP-P0020 (cookie-banner auto-display):
  tracking-adjacent behaviour becomes explicit opt-in. Evidence:
  `docs/security/GHSA-4.1.1-draft.md`.
- **security** — DEP-P0013 (GlassCanvas string action execution): RCE-shaped
  API removed on the patch line. Evidence: `docs/security/GHSA-4.1.1-draft.md`.
- **legal** — DEP-P0015 (`--glass-font-sans` Aeonik family): bundled font with
  unconfirmed licence removed per D-31. Evidence:
  `docs/release/decisions/4.1.1-font-aeonik.md`.

`verify-deprecations` exempts entries carrying `exception` from the
`removeIn: '5.0.0' ⇒ since >= 4.2.0` train rule; entries without an exception
still must ship in a 4.x minor ≥ 4.2.0. The exemption exists for exactly this
window — the trust patch is the only 4.x patch line allowed to announce
deprecations outside the minor train.
