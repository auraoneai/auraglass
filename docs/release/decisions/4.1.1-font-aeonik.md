# D-31 — Aeonik removal (font decision, 4.1.1)

**Outcome (default): licence unconfirmed → removed.**

The Aeonik family shipped in `src/styles/fonts/` as 12 woff2 files plus `src/styles/aeonik.css`, but no licence could be confirmed for redistribution inside the npm tarball. Per REQ-PLAT-54 the default outcome applies: the files and the `@import` are removed and `--glass-font-sans` resolves to the system stack (`system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`) in `variables.css`, `tokens/generated.ts`, `tokens/designConstants.ts`, and `theme/tokens.ts`; inline poster/cover SVG text uses `Arial, sans-serif`.

If the owner later supplies a licence + `LICENSE-FONTS` file, the alternative path restores the family and requires `dist/styles/fonts/LICENSE` to be packed (tarball ≤ 9.70 MB). The assertion is `scripts/ci/verify-font-tarball.js`, which auto-detects the outcome by whether `src/styles/fonts/` contains Aeonik files.

Owner action recorded: no licence was supplied by the tag date → default executed.
