## Question 1: compat date adapters (REQ-SURF-04)

The compat date adapters depend on date-library peers. How are those peers
isolated behind `aura-glass/compat`?

- **Lazy import.** The adapters import the date peer dynamically, so the
  `aura-glass/compat` graph has no static edge to it.
- **Own `./compat/date` subpath (default).** The adapters move to their own
  export, and `aura-glass/compat` does not reference them.
- **Documented peer requirement.** This is what open PR #341
  (`next-fin/surf-04-peers`, head `70a7ee9c2` at the time of this draft)
  implements: a note in `src/compat/index.ts` plus
  `tests/data/exports/peer-isolation.test.ts` (a metafile gate). If you choose
  lazy or subpath instead, #341 adds that change before it merges.
