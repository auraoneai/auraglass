# Decision record — 4.1.1 font licence (Aeonik removal)

**Status:** accepted for 4.1.1 trust patch (REQ-PLAT-54).
**Context:** D-31 — the bundled Aeonik family ships without a confirmed
licence. `--glass-font-sans` already resolves to the platform system stack
per the deprecation note (`deprecations.generated.ts`), but live font-family
values still named `Aeonik` first in several files, and
`designConstants.ts` carried a stray leading quote in `TYPOGRAPHY.fontFamily.sans`.

## Decision

Aeonik is removed from every active font-family declaration. The full
system stack is the only family:

`system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`

## Files touched

- `tokens/personas/default.json` — persona `typography.fontFamilies.sans`.
- `src/tokens/generated.ts` — regenerated output is byte-identical to the
  edit (verified: `node scripts/tokens/build.mjs --platform bridge-4x`
  emits the same file).
- `src/styles/variables.css` — `--aura-font-sans` stack.
- `src/tokens/designConstants.ts` — stray leading quote fixed;
  `fontFamily.sans` now holds the same stack.
- `src/components/charts/GlassDataChart.tsx` — Chart.js `defaults.font.family`.
- `src/components/media/GlassAdvanced{Video,Audio}Player.stories.tsx` —
  preview SVG `font-family` attributes → `system-ui,Arial,sans-serif`.

`src/internal/deprecations.generated.ts` keeps the Aeonik name in the
migration note (it must reference the removed family).

## Gates

- `scripts/ci/verify-pack.js` — fails the pack when a tarball member path
  or any packed `.css` still contains `Aeonik` (deprecation prose in
  `.d.ts`/`.js` is exempt by design).
- `tests/ci/tarball-fonts.test.ts` — source-level fixtures: no live
  `font-family` declaration may name Aeonik, personas and generated.ts
  stay consistent, the verify-pack check exists, and a poisoned fixture
  string still trips the pattern.

Before/after composites (Storybook chart + media previews) are CI-only
artifacts per the repo's visual-testing rule; they attach to the 4x CI
verify-pack/storybook legs.
