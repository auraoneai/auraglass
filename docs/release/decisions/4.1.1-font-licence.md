# Decision record — 4.1.1 font licence (Aeonik removal, D-31)

**Status:** accepted for the 4.1.1 trust patch (REQ-PLAT-54). This is the one
font decision record; it replaces the former duplicate
`4.1.1-font-aeonik.md`.

**Outcome: default (licence unconfirmed by the tag date) → Aeonik removed.**
No redistribution licence for the Aeonik family was supplied by the owner, so
the default branch of REQ-PLAT-54 ships: the 12 `src/styles/fonts/Aeonik-*.woff2`
files and `src/styles/aeonik.css` are deleted, the `@import "./aeonik.css"` is
gone from `src/styles/index.css`, and every live font-family is the system
stack.

## The stack

`system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif`

## Variable name

REQ-PLAT-54 and the `DEP-P0015` entry name the variable `--glass-font-sans`.
The 4.x stylesheets never defined a variable of that name: the sans stack has
always been `--aura-font-sans` (`src/styles/variables.css:30` at `v4.1.0`,
`15b6de6f7`, where it read `"Aeonik", system-ui, …`). `--glass-font-sans` in the
PRD and in `DEP-P0015` therefore means `--aura-font-sans`; no new
`--glass-font-sans` variable is added, because a new public CSS variable is a
C-E change, which a 4.x patch does not allow.

migration note: it must name the removed family.

## Gates

- `scripts/ci/verify-pack.js` fails the pack when a tarball member path or any
  packed `.css` still contains `Aeonik` (deprecation prose in `.d.ts`/`.js` is
  exempt by design).
- `tests/ci/tarball-fonts.test.ts`: no live `font-family` declaration names
  Aeonik; the persona and `generated.ts` hold the same stack; every file in the
  table above carries exactly this stack; the verify-pack check exists; a
  poisoned fixture string still trips the pattern.

## Alternative (not taken)

If the owner later supplies a written redistribution licence, the family can be
restored with `LICENSE-FONTS` committed, `dist/styles/fonts/LICENSE` shipped and
listed in `files`, and a README notice; `verify-pack.js` then asserts the licence
file instead of 0 Aeonik paths.

## Visual change

Every rendered text node changes family, so this is a labelled visual change
(`docs/release/visual-fixes/4.1.1-font-fallback.md`). The before/after
composites (`15b6de6f7` vs the release SHA, 1440×900 and 390×844) are produced
by `plat:test:visual-4x`; their artifact URL is recorded in that file after the
first run.
