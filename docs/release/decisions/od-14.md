## Question

`auraoneai/auraglass` has one maintainer. Code-owner review on `docs/release/**`
and on the protected lines needs a second approver. Which review model applies?

## Options

1. **Second human reviewer.** Name the GitHub account. It is added to
   `.github/CODEOWNERS` (C-10, through `contract/v1.2-final` on `main`, OD-16).
2. **Review bot.** Name the GitHub App and the rules under which its approval counts.
3. **Documented admin bypass.** The owner merges with an admin bypass. Each use
   is recorded on the PR, with the GitLab pipeline URL that was green on the head SHA.
4. **Defer (default).** Branch protection is not applied, and AC-FIN-25's live
   half stays open.
