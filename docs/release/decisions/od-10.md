## Question

Should npm trusted publishing (OIDC) for `aura-glass`, and then `@auraglass/*`,
be re-pointed to GitLab CI/CD, so that `plat:publish:npm` publishes with
`--provenance` and no npm token exists anywhere?

## Options

1. **Configure trusted publishing to GitLab.** Use the values below.
2. **Defer (default).** Nothing publishes from GitLab. `plat:publish:npm` fails
   closed at `npm publish --provenance` with a 401 (W-7). No tag (`v4.1.1`,
   `v4.2.0`, …) can publish.

## Owner action

On npmjs.com, for each package (`aura-glass`, then `@auraglass/cli`,
`@auraglass/registry`, `@auraglass/mcp`, `@auraglass/labs`, or their unscoped
fallbacks per OD-2): **package → Settings → Trusted publishing → GitLab CI/CD**,
with these values:

- namespace `chahal-foundation-group/github-auraoneai`
- project `auraglass` (id 87152036)
- file `.gitlab-ci.yml`
- job `plat:publish:npm`
- environment `npm-publish`

The scoped packages need the `@auraglass` org first ([od-2.md](./od-2.md)).
