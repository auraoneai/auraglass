## Question 1: app-shell token namespace (REQ-MAT-04)

Are the app-shell CSS variables public API (`--ag-app-shell-*`, which then belong
in `PUBLIC_CSS_VARS` through C-7, OD-16), or private (`--_ag-app-shell-*`)?

- **Private `--_ag-app-shell-*` (default).** This is FIN-A's #120-v2 default. No
  contract addition is needed.
- **Public `--ag-app-shell-*`.** SURF owns the names and they are added to
  `PUBLIC_CSS_VARS` (C-7).

## Question 2: shipping-asset PNG allowlist (REQ-QUAL-60)

Should PNGs under `src/**/assets/` be admitted to the package, or relocated?

- **Allow `src/**/assets/` (default).**
- **Relocate.** Move the PNGs out of `src/`, and FIN-G's asset gate rejects any
  PNG under `src/**`.

FIN-G prepares a separate decision-record draft for the PNG allowlist (FIN-G
owner item 6). It cross-references this record.
