# OD-12 — Custom domain on Pages

Draft prepared by the FIN-H agent (H3-5, task FIN-473). The agent has not made
this decision and does not fill in `decidedBy`, `decidedAt` or `evidence`.

## Question

Should the docs site and registry be served from the custom domain
`auraglass.dev` on GitLab Pages, instead of the default Pages URL
(`https://chahal-foundation-group.gitlab.io/github-auraoneai/auraglass/`)?

## Options

1. **Custom domain `auraglass.dev`.** This needs a DNS change and domain
   verification. The registry URL in the docs becomes `https://auraglass.dev/r/*.json`.
2. **Default.** `DOCS_BASE_URL = $CI_PAGES_URL`.

## Owner action (option 1)

GitLab 87152036 → **Deploy → Pages → New domain** → `auraglass.dev`. Add the
verification TXT record and the CNAME/A records at the DNS provider, and enable
the automatic Let's Encrypt certificate.

## Default (PRD-F §5.9)

`$CI_PAGES_URL`.

## Blocks

REQ-FIN-26 (REQ-PLAT-07): the Pages URL used by AC-FIN-26 and the registry URL in
the docs.

Set `status: decided` or `status: defaulted`, then fill in `decidedBy`,

Pages settings page and `curl -sI https://auraglass.dev/` output). Agents never
