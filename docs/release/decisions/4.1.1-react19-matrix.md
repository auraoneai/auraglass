| Leg | Command | Covers |

- `tests/react19/element-ref-spy.ts` fails any test that logs a `console.error` matching `/element\.ref/`. Both leg files import it, and the `unit-react19` config adds it as a setup file for every test; it is idempotent. The config appends it to the repo `setupFilesAfterEnv` instead of passing `--setupFilesAfterEnv` on the command line, because the CLI flag replaces the configured list (dropping jest-dom and `src/utils/testSetup.ts`). A `child.ref` read in `Slot` on React 19 turns both legs red.
- `tests/react19/runtime.ts` makes the runtime assertion exact: 19 inside a leg (`AG_REACT19_LEG` set by the matrix), otherwise the major of `devDependencies.react`.
- CI job (`ci/plat.gitlab-ci.yml`, owned by FIN-B, branch `4x11-fin/b-react19`): installs `react@19 react-dom@19 @types/react@19 @types/react-dom@19` with `--no-save` before jest, without the `PENDING` guard, so a missing leg fails.
- `allow_failure: false` for both `plat:test:react19` legs is set by FIN-B from the first green pipeline on this line, recorded as a `ci/plat/activation.json` row with the job URL. This PR does not change it.
