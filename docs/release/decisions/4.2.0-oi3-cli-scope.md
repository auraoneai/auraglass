# OI-3 — cli package scope for the 4.x line (D-23 fallback)

The 5.0 CLI ships as `aura-glass-cli` on the `next` line. For the 4.x line the unscoped fallback decision (D-23, made once by PLAT before 4.2): the 4.x bridge **does not publish a scoped CLI package**; `aura-glass-cli` remains the package name and `packages/cli` stays at `0.x` while its surface is in flux — the scoped name lands with the 5.0 GA. Recorded per §14.4 / PLAT-156's "cli@0.x note" requirement.
