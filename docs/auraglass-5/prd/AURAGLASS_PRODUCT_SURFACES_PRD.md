## 1. Problem

AuraGlass 4.1.0 has no trustworthy product surface. Every screen a product team builds sits inside an app frame, shows data, hosts an AI conversation or puts glass over media, and all four families are broken, fake or duplicated:

1. **The app frame does not lay out.** About 32 of the ~104 `glass-*` utilities in `src/app-shell/components.tsx` have no CSS selector, so in Chromium at 1440 px the `saas-admin-shell` rail stacks above `GlassMain` instead of beside it. There is one responsive rule for 343 responsive class uses. Two `GlassAppShell` and two `GlassSplitPane` exports share names on different entries. The split pane measures `e.clientX / window.innerWidth`. Page navigation is built as `role="tab"` with no panels, `GlassTabs` wraps every tab set in `role="navigation"` with colliding ids, and a collapsed sidebar is `aria-hidden` with focusable children. Shell stories fail contrast on their own stage (1.12–2.14:1), render 21–29 backdrop filters at nesting depth 4 and drop to 19–23 fps.
2. **The data layer is heavy, fake and crashes.** Three chart engines (~5,500 lines) ship chart.js (~167 KB) in a `GlassButton`-only import and overwrite consumer-global `Chart.defaults`. Four tables, none virtual (`GlassVirtualTable` renders `GlassDataTable`); `GlassDataTable` calls hooks conditionally and throws when a "consciousness" flag toggles. The date picker fails the APG date grid, `format` is a no-op, week numbers are a comment, the root import loads 304 `date-fns` modules and `dateAdapters.ts` calls a `require` that always throws in browser ESM. Trees have no keyboard model. The query builder mutates state in render. `./data` resolves to the root bundle.
3. **"AI" is a simulation and a backend.** `src/components/ai/` root-exports GAN, DeepDream and style-transfer simulations built on `Math.random`. `GlassChat` draws suggestions from a random-weight engine, `GlassChatInput` hands consumers `new Blob(["mock audio data"])`, and there is no message-part model, streaming, tool call, citation or approval. The package ships `openai`, `@google-cloud/vision` and an Express backend to every consumer.
4. **Media is mock and glass is never shown over media.** Players ship mock waveforms and transcripts, `isStorybookDataMedia` forces consumer `data:video/` sources to poster mode, three components hijack page-wide `keydown`, the waveform is `sin` plus `Math.random`, the backdrop "sampler" reads DOM colours at 9 points and treats transparent wrappers as black, and eight ambient backdrops loop with random particles. 351/356 certification screenshots are near-white; no story shows glass over media.
5. **Nothing governs new capability.** Missing capabilities (column resize, `TimePicker`, `ToolCall`, `Citation`, scrubber, `DateTimePicker`, commerce, presence) are spread across documents, while 4.x novelty (quantum, consciousness, AR, GAN) is being deleted with nothing stopping its return.

5.0 must replace all of this with one app frame, one navigation family, one data and date layer, a presentational AI layer, an honest media core, and a governed expansion path, all built on the 5.0 material, certified in the environment matrix, and delivered by one stream that never waits for another (§21).

## 3. Desired end state

At 5.0.0 GA (and 5.1 where marked):

1. **Exact entries.** Every SURF entry exports exactly its contract `ENTRIES` value list (contract §4.7), and the root exports exactly `ROOT_EXPORTS.surf` through `src/root/surf.ts`. Nothing media, data, AI or shell-related leaks into the root beyond those nine names. `./charts` is absent from the 5.0.x `latest` exports map and ships in 5.1.
2. **One app frame.** `AppShell` lays out at 390, 768, 1024, 1440 and 1920 px with zero consumer CSS, in a Vite app without Tailwind and in Next 15/16, from SURF CSS (named grid areas and container queries). Sidebar has expanded, rail and collapsed states, persists them by cookie, becomes a modal drawer in compact and medium containers, and never leaves hidden content focusable. `Main` is the single scroll owner; floating bars write `--ag-scroll-padding-*`.
3. **Correct navigation.** Page navigation (`Sidebar.Nav`, `TabBar`, `Breadcrumbs`, `Pagination`) is links in a labelled `<nav>` with `aria-current="page"`, composable with any router through `render`. View switching (`Tabs`, `TabBar semantics="tabs"`) is Base UI Tabs with unique ids and APG keyboard. `Command` scores without building a RegExp from input.
4. **Real data and date.** `Table` is one TanStack table with sorting, range selection, resize, pin, reorder, server pagination and virtualization to 100,000 rows, on the non-blurred `content-raised` material. `TreeView`, `FilterBar` (immutable filter model), `StatCard`, `Sparkline`, `ChartFrame` (adapter contract, accessible legend, table fallback) and `Timeline`/`ActivityFeed` replace about 30 4.x names. `./date` runs on React Aria with `@internationalized/date` values and passes the APG date-grid and spinbutton scripts. No chart.js, react-chartjs-2 or date-fns anywhere.
5. **Presentational AI.** `./ai` renders AI SDK `UIMessage` parts with no mapping code, streams without jitter, announces once, supports six tool states with approval, reasoning disclosure and inline citations, and makes no network or provider call. Model picker, artifacts, trace, eval, markdown, voice and the AI SDK binding are registry items; the `ai-workspace` block's route calls **Kiro Prism** (`https://prism.auraone.ai/v1`) server-side.
6. **Honest media.** One headless `useMediaElement` core over the consumer's own `<video>`/`<audio>`; `MediaControls` is the canonical `clear`-over-media demonstration and passes OCR contrast over all eight scenes; `ImageViewer` is a real lightbox; `CarouselRail` is an APG carousel with autoplay gated as a loop. The library samples only pixels it owns, once per source, and never lowers a contrast floor. `Backdrop` has five static presets; nothing loops unless `allowContinuous` and motion `full` resolve.
7. **Governed expansion.** `docs/auraglass-5/capability-ledger.json` lists every new capability with one owner stream, a delivery form and a release; CI fails on orphans, duplicates, re-admitted rejected novelty, or an export-budget breach (root ≤160, total ≤250 value exports, D-15). Commerce, presence, comments, audit log and permissions ship as registry blocks/items in 5.1/5.2; spatial work stays in `@auraglass/labs`.
8. **Certified.** All 24 SURF flagships (14, 22–44) have the architecture §11.3 deliverables (meta, part contract, selector table, registry usage, APG script, budget row, perf grade ≥C, L7 baselines, codemod fixture per absorbed name), and every lane L1–L12 is `pass` for every SURF subject on the GA SHA (contract G-01, G-04).
9. **Migrated.** Every absorbed 4.x name has a SURF deprecation entry that shipped in a published 4.x minor, a compat adapter or an explicit no-successor TODO, and codemod mappings with fixtures; the frozen 4.x fixture's SURF cases migrate with 0 TODOs on the flagship subset.

A structural mirror of the AI SDK `UIMessage`, so `useChat().messages` type-checks as `AgMessage[]` with no cast and no `ai` import in shipped code:

```ts
export type AgRole = 'user' | 'assistant' | 'system' | 'tool';
export interface AgMessage<M = AgMessageMetadata> { id: string; role: AgRole; parts: readonly AgPart[]; metadata?: M }
export interface AgMessageMetadata { createdAt?: string | number; model?: string;
  status?: 'pending' | 'streaming' | 'complete' | 'error' | 'aborted'; usage?: AgUsage }
export type AgPart =
  | { type: 'text'; text: string; state?: 'streaming' | 'done' }
  | { type: 'reasoning'; text: string; state?: 'streaming' | 'done' }

  input?: unknown; output?: unknown; errorText?: string; approval?: { id: string; approved?: boolean; reason?: string } }
export type AgToolSdkState = 'input-streaming' | 'input-available' | 'approval-requested' | 'approval-responded'
  | 'output-available' | 'output-error' | 'output-denied';
export type AgToolDisplayState = 'queued' | 'running' | 'needs-approval' | 'succeeded' | 'failed' | 'denied';

  cachedInputTokens?: number; contextWindow?: number; costUsd?: number }
```

`ToolCall.displayState(part)` maps `input-streaming` → `queued` ("Preparing"); `input-available` and approved `approval-responded` → `running` ("Running"); `approval-requested` → `needs-approval` ("Needs approval"); `output-available` → `succeeded` ("Done"); `output-error` → `failed` ("Failed"); `output-denied` and denied `approval-responded` → `denied` ("Denied"). `denied` extends architecture §11.2 row 41 (C-E; a user decision is not an error).

### 4.6 Media core and owned-pixel sampling

- `useMediaElement(ref)` subscribes one per-element external store to `play`, `pause`, `ended`, `durationchange`, `loadedmetadata`, `progress`, `seeking`, `seeked`, `waiting`, `canplay`, `volumechange`, `ratechange`, `error`, `enterpictureinpicture`, `leavepictureinpicture`, `timeupdate`. React snapshots publish at ≤4 Hz; playback progress is written as `--_ag-media-progress` on `[data-ag-media-root]` from one MAT `subscribeFrame` subscription (S-13), only while playing, visible and intersecting.
- Sampling pipeline: source (`<img>` decoded, or video `poster`/first `loadeddata`) → 32×32 canvas (`OffscreenCanvas` when available) → BT.709 relative luminance on linearised sRGB, implemented in SURF's `src/media/sampling/luma.ts` (MAT's `src/theme/color.ts` is not a contract module path, so SURF does not import it; both implement the same WCAG formula) → `{ mean, p10, p90, stdev }` → `classifyTone` → `data-ag-media-tone` + `--_ag-media-luma` on the owning root; cached per source. The library never samples arbitrary DOM, points or selectors.

## 11. Migration concerns

1. **Pixels change everywhere.** Every SURF surface moves to the 5.0 material (B11) and content stops being glass (B12): tables, docked inspectors and messages lose blur. Apps that relied on `glass-on-light` ink pinning see light ink on dark chrome; that is the contrast fix. The 4.3 `data-ag-preview="v5"` preview covers none of SURF's flagships (D-19); teams re-baseline at 5.0 beta.
2. **Layout moves into the library.** Consumer overrides of `.glass-app-shell*`, `.glass-sidebar*`, `.glass-top-bar`, `.glass-status-bar`, `.glass-data-table-*` and `glass-surface-primary` calendar days must be deleted; PLAT's `doctor --v5` flags those selectors from the meta `migration.selectors` tables, and selector tables ship in the migration guide.
3. **Container, not viewport.** The 4.x `mobileBreakpoint` becomes the fixed 600 px container breakpoint; a shell inside a narrow pane renders compact (`layout="desktop"` overrides). SSR now renders the right layout, so `useEffect` flash workarounds can go.
4. **Router integration.** Handler-only rail and tab-bar items are rewritten to `render={<button onClick>}` (no TODO, behaviour preserved, dev warning recommends links); the guide shows the router-link follow-up.
5. **Silent dependency breaks.** Consumers who imported `chart.js`, `react-chartjs-2` or `date-fns` without declaring them break at 4.2 (optional peers) or 5.0; the `deps` codemod rows add them and `doctor` reports them; release notes list these first. `./date` consumers must install `react-aria-components` and `@internationalized/date`; if the D-13 alpha check shows Base UI coverage, the RA peer is dropped before beta (the value-type peer stays).
6. **No chart engine at 5.0 GA.** Paths: stay on 4.x LTS (12 months), wrap a chart library in `ChartFrame` (the guide preserves `GlassDataChart` `datasets`/`labels` with a chart.js adapter), or use 5.1 `Chart` (on `next` as `@tier preview` before 5.1.0).
7. **Date values and time zones.** `Date` → `CalendarDate`/`ZonedDateTime`; a local-midnight `Date` converted in a UTC server shifts a day, so the compat adapter converts on the client only and requires `timeZone` on the server. Fixed display formats become `locale` choices; the codemod leaves a TODO, never a guess.
8. **AI data model is manual.** Apps already on the AI SDK delete their mapping code and pass `messages`; human-chat apps keep the compat adapter through 5.x or stay on 4.x LTS. Enter no longer submits during IME composition; the thread no longer jumps while the reader is scrolled up; voice capture needs the `ai-voice-input` item (4.x sent a fake Blob). Any AuraOne consumer that called models through `aura-glass/services/ai/*` moves to an app-side route through Kiro Prism, not to a library API.
9. **Media moves to the consumer's element.** 5.0 never sets `src`; player call sites get a registry-item pointer and a TODO. Keyboard shortcuts are scoped to the focused player (`shortcutTarget` widens the scope). `ImageViewer` requires `alt` per item. Carousel autoplay, backdrop drift and background video are off by default and gated by `allowContinuous` + motion `full`; reduced-motion users can never be opted in. Cross-origin images without CORS get no tone but keep the `media` floor.
10. **Registry, not exports.** Commerce, pricing, presence, comments, query builder UI, model picker, artifacts, trace, eval, galleries and players are copy-in source; `doctor --v5` prints the `npx @auraglass/cli add <id>` command per 4.x import. Rejected families (quantum, consciousness, AR, GAN, particles in core) have no successor; `doctor` names their X-R id.
11. **Rollback.** Each removal family is one revertable PLAT PR; SURF's components do not depend on any legacy file, so reverting a removal never breaks a SURF entry.

## 15. Accessibility requirements

WCAG 2.2 AA is the floor for every SURF flagship, block and item; failures block certification.

- **Patterns (APG):** Tabs (Tabs, TabBar `tabs`), Disclosure (Sidebar groups, Inspector sections, ToolCall, Reasoning, SourceList), Dialog modal (drawer, inspector sheet, CommandPalette, ImageViewer, date popups), Combobox with listbox (Command), Window Splitter (ResizablePanels, Table resize), Breadcrumb, landmarks (AppShell), table and data grid (Table), tree view (TreeView), date grid and spinbuttons (date), Toolbar and Slider (MediaControls, Scrubber, Volume, Rate), Carousel (CarouselRail, autoplay toggle first), toggle buttons (FilterBar quick filters, ChartFrame legend, Chip), meter (UsageMeter), progressbar (NowPlayingBar).
- **Current location:** exactly one `aria-current="page"` per navigation, never combined with `aria-selected`.
- **Hidden content** is `inert`/`hidden`, never `aria-hidden` over focusable descendants.
- **Names:** every flagship requires an accessible name (`aria-label`, `caption` or `label`) with a dev warning when missing; icon-only controls are labelled; decorative media is `aria-hidden` with `alt=""`.

- **Non-colour cues:** trend arrows + text, intent icons + text, selected rows by `aria-selected` + a 2 px start-edge indicator + fill, tool/step states icon + text, meter warning/critical text, legend swatch + label.
- **Contrast, preferences, focus, targets, motion:** REQ-SURF-188..193.
- **Content safety:** model text is never injected as HTML; links from model output render only through the consumer's `renderText` or as sanitized `SourceList` items (http/https).
- **Captions:** `MediaControls.Captions` exposes every captions/subtitles track; the library generates no captions or transcripts.
- **Language:** `Intl` with the passed or document locale; `dir` follows it; all strings overridable (REQ-SURF-10).
- **Manual lane (L13, GA blocker G-09):** VoiceOver (macOS Safari, iOS Safari), NVDA + Chrome, TalkBack + Chrome and physical touch for all 24 flagships, the six AppShell product shells and the `ai-workspace`, `data-workspace`, `media-viewer` blocks, including "a streamed answer is announced once" and "approval request is announced".
