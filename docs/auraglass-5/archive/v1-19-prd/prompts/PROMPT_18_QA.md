## Common rules (each sub-prompt restates them)

- Repo `/Users/gurbakshchahal/platforms/AuraGlass`. Architecture decisions win. Any deviation goes in the final report with evidence.
- **Remote only for heavy work.** Browsers (all engines), Storybook builds, screenshots, OCR over captures, perf, tarball installs and container builds run only on GitHub-hosted runners (the repo is believed public, re-verify per PRD §21 OI-QA-02; read `/Users/gurbakshchahal/.config/agent-policy/reference/ci-selection.md`) or on the gated EC2 runner through skill `auraone-remote-run` (read `/Users/gurbakshchahal/.config/agent-policy/reference/remote-execution.md` first). Never use Docker or a browser on the Mac. The EC2 egress-proxy CA expired 2026-09-27, so EC2 runs use the offline bundle over the S3 gateway path. Never rotate the CA (operator action).
- **No fake completion.** None of the following count as done: a mock, stub or placeholder reported as done; `.skip`/`.only`/`.todo`/`test.fixme`/`xit`; `--passWithNoTests`; `retries` to hide flakes; lowered thresholds; new allowlist/exemption entries added to get green; `--update-snapshots`/`-u` outside the reviewed baseline-update job; `continue-on-error`/`|| true`; hand-written evidence JSON. A lane that is red because another PRD is missing stays red with `provider missing: <path>`, and you report it BLOCKED.
- Evidence = CI artifacts keyed by SHA (D-32). Never commit `$CERT_OUT`, captures, reports or perf JSON. The only committed PNGs are baselines, scenes and fixtures of 40 KB or less.
- Do not touch the uncommitted PRD-TRUST edits (`scripts/ci/run-next-integration.js`, `scripts/ci/run-vite-integration.js`, `scripts/ci/verify-pack.js`, `reports/3.2-release/vite-integration.json`).
- Exact-pinned devDependencies only, and only where a prompt names them. Use `node_modules/.bin/*`, not `npx`.
- Agents do not judge screenshots. Visual review means remote capture plus human review records (L14).
