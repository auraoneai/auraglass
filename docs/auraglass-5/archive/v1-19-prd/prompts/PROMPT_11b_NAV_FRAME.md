## Steps

1. **`AppShell.tsx` (REQ-NAV-01, -05, -08, -12, -36).** Namespace object `AppShell = { Root, Main, PageHeader, SkipLink, SidebarToggle, InspectorToggle, Controller }`. `Root` renders one `<div class="ag-app-shell" data-ag-part="root" data-ag-sidebar data-ag-inspector data-ag-layout data-ag-sidebar-side data-ag-density data-ag-backdrop data-ag-persist-key>` from props `defaultSidebar="expanded"`, `defaultInspector="closed"`, `sidebarSide="start"`, `layout="auto"`, `density`, `persistKey`, `backdrop`, `labels`. Children place themselves via `data-ag-slot` (`top|sidebar|main|inspector|status|tabbar`) set by each part, so `memo`/HOC wrappers work. `Main`: `<main id={id ?? useId-free server id from props or generated by `React.useId`} tabIndex={-1} data-ag-slot="main" class="ag-app-shell__main">` with `layer="content"` material. `SkipLink`: first child, `href="#<mainId>"`, visually hidden until `:focus-visible`, label `labels.skipToMain ?? "Skip to main content"`. `PageHeader`: `title`, `headingLevel` (1–6, default 1), `eyebrow`, `description`, `actions`, `tabs`; actions wrap at `@container ag-app-shell (width < 600px)`. No `role="region"`, `role="main"`, `role="contentinfo"` anywhere.
2. **`appShellStore.ts` (REQ-NAV-09, -11).** `getAppShellStore(root: HTMLElement)` (WeakMap per root) with `getSnapshot`, `getServerSnapshot` (= rendered attribute), `subscribe`, `setSidebar`, `setInspector`. Writes `data-ag-*` on the root, sets `data-ag-animating` for `--ag-duration-medium` only when `data-ag-motion` resolves `full`, and, when `data-ag-persist-key` is present, writes `serializeAppShellCookie`. Controlled mode: `setX` calls the handler only.
3. **Islands (REQ-NAV-20 inline half, -11).** `SidebarToggle` = PRD-08 `IconButton`, finds root with `ref.current.closest('[data-ag-part=root].ag-app-shell')`, uses `useSyncExternalStore`. One `ResizeObserver` per root (shared via the store) derives `mode: compact|medium|expanded|wide` for ARIA only. Expanded/wide: toggles `expanded ↔ collapseTo` (`"rail"` default), `aria-label` "Collapse sidebar"/"Expand sidebar" from `labels`, `aria-controls` = sidebar id, no `aria-pressed`/`aria-expanded`. Compact/medium ARIA (`aria-expanded`, `aria-haspopup="dialog"`, `aria-controls` = drawer popup id) is applied in a layout effect; the drawer itself lands in 11c (this prompt exposes `onRequestDrawer` on the store). `shortcut` prop (default `false`) registers one `keydown` for `mod+B`. `InspectorToggle` mirrors it for `data-ag-inspector`. `Controller` (`sidebar`, `onSidebarChange`, `inspector`, `onInspectorChange`) wraps the root and registers controlled handlers on the store.
4. **`TopBar.tsx` (REQ-NAV-25..29).** `TopBar = { Root, Leading, Title, Center, Trailing }`. `Root` = `<header data-ag-slot="top" class="ag-top-bar" data-ag-placement>`; no explicit `role`: per HTML-AAM a `<header>` is a banner only when it is not inside `main`/`aside`/`nav`/`section`/`article`, so as a direct child of `AppShell.Root` it is the banner and inside `Main` it is not. Never add `role="banner"`. Material `layer="chrome" thickness="regular"`. Renders exactly one PRD-MAT `ScrollEdge edge="top"`; the `scrollEdge` prop `soft|hard|none` maps to `ScrollEdge edgeStyle="soft"|"hard"` (emitted `data-ag-edge-style`), and `none` renders no edge (SC-22). A module-level dev registry keyed by scroll container + edge warns on a second instance. `Center` hides below 600px unless `keepCenter`; `Title` single-line ellipsis. Under `[data-ag-transparency=solid]` no shadow; forced colors: `outline`-based bottom edge.
5. **`StatusBar.tsx` / `StatusBarLive.tsx` (REQ-NAV-33).** `StatusBar.Root` content-sunken thin material, **no role**; `Item` static; `Live` (client) calls the PRD-A11Y announcer (A11Y-054), polite default, 1000 ms debounce, skips first mount.
6. **`MobileShell.tsx` (REQ-NAV-34, -07).** Server preset: `AppShell.Root layout="mobile"` with `topBar` (overlay `TopBar`), `children` (Main), `tabBar` slots; CSS sets `--ag-scroll-padding-bottom: calc(var(--ag-app-shell-tabbar-height) + env(safe-area-inset-bottom) + var(--ag-space-2))`.
7. **Theming (REQ-NAV-14).** Active indicator, focus ring and tab indicator read `--ag-accent*`/PRD-A11Y focus tokens only; verify `createBrandTheme({ brand })` recolours them.
8. **Landmark uniqueness (REQ-NAV-37).** Dev-only registry warns when two landmarks of one role share an accessible name.
9. **Barrel.** Add `AppShell`, `TopBar`, `StatusBar`, `MobileShell`, `parseAppShellCookie` to `src/app-shell/index.ts` (plain re-exports, no directive).
