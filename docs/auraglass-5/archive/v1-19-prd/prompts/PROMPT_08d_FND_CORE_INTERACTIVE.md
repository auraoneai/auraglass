## 5. Common build rules (every component here)
- Wrap exactly one Base UI part per AuraGlass part (PRD §4.2 Switch shape). `"use client"` only in `*.client.tsx`. Index files carry no directive. Base UI types never appear in public props: map callbacks through `toChangeDetails`. The selection contract is `value`/`defaultValue`/`onValueChange(value, details)`, `checked`/`onCheckedChange`, `open`/`onOpenChange`. There is no `onChange` (only a native input `onChange` on an `input` part), no `asChild` (`render` only), and portals use `usePortalContainer()`.
- Every rendered part gets `data-ag-part`. `data-state` comes from `toDataState()` wherever the Base UI part exposes open/checked/active/expanded. Base UI `data-*` attributes pass through.
- Material only via `materialProps()` (roles per PRD §4.5). Disabled dims through `--_ag-surface-alpha`, never `opacity` on `[data-ag-surface]` (REQ-FND-10). No colour/duration/easing literals and no `!important`; CSS sits in `@layer ag.components`, uses `@container` and `--ag-*` vars.
- Targets are ≥24×24 CSS px, and ≥44×44 under `(pointer: coarse)` through A11Y's internal `HitArea` span (`data-ag-part="hit-area"`, A11Y-065/066; architecture errata E-08: a span, not a pseudo-element) without a visual change. This applies to Chip remove, Rating items, ColorPicker thumbs, Accordion triggers, Tour buttons and the FileUpload button. The focus ring is PRD-05's token (2 px two-tone outline + offset, `Highlight` in forced colors); never `outline: none`.
- `meta.ts` (`tier: 'T2'`, `rsc`, `apg` URL, `budgetKb`, `variants`, `migration` (4.x names and props it absorbs, SC-27) and `selectorMigration` from the seed's classes and roles). Material axes and status follow SC-24 (`variant`, `thickness`, `prominent`, `refraction`; status `intent`; no `material`, `elevation`, `as` or `tone`). Stories `Core/<Name>`: `Default`, variant matrix, `States`, `ReducedTransparency`, `ForcedColors`, `ContrastMore`, `RTL`, `Mobile390`, and `Keyboard` with a `play` function that mirrors the APG spec. Imports come from the public entry only.
- Unit test `<Name>.test.tsx`: controlled/uncontrolled parity, `onValueChange` receives `details.reason`, the `ref` reaches root, `jest-axe` structural rules, and the named cases below. Register the name in `contract-coverage.json`, append its prop type to `OWNED_PROP_TYPES`, and regenerate docs.
- Ref callbacks that attach observers return cleanup (`ScrollArea` ResizeObserver; architecture §9.2). Code review checks it, so state it in the PR body.
