## Common rules (each sub-prompt restates them)

- Repo `/Users/gurbakshchahal/platforms/AuraGlass`. Architecture decisions win; any deviation goes into the final report with evidence.
- Remote-first: Storybook builds, every Playwright run (all engines), screenshots, perf traces, full `npm run build`, tarball installs and Node cold-import timing run on GitHub-hosted runners (repo is public; read `/Users/gurbakshchahal/.config/agent-policy/reference/ci-selection.md`) or on an ephemeral EC2 worker via the `auraone-remote-run` skill (read `/Users/gurbakshchahal/.config/agent-policy/reference/remote-execution.md` first). Never Docker or a browser on the Mac. The EC2 egress CA expired 2026-09-27 (`autopsy/runtime-remote.md` "Operational notes"): EC2 jobs use an offline bundle uploaded through the S3 data path.
- No fake completion: no mock or placeholder implementation reported as done, no `.skip`/`.only`/`.todo`/`xit`/`test.fixme`, no `--passWithNoTests`, no lowered thresholds, no new allowlist entries to get green, no `--update-snapshots`/`-u`, no `continue-on-error: true`. A gate red because another PRD's work is missing stays red and is reported BLOCKED with that PRD.
- Evidence is CI artifacts keyed by SHA (D-32). Never commit `reports/**`, `perf-results.json`, `perf-grades.json` or screenshots.
- Do not touch the uncommitted PRD-00 edits at HEAD (`scripts/ci/run-next-integration.js`, `scripts/ci/run-vite-integration.js`, `scripts/ci/verify-pack.js`, `reports/3.2-release/vite-integration.json`).
- New devDependencies: exact pins only, and only where a sub-prompt names one. Use `node_modules/.bin/*`, not `npx`.
