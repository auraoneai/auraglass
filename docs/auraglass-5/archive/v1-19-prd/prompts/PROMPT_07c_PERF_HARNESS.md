## Steps

1. **PERF-056 `bci.mjs` + `bci.test.ts`.** Pure function `computeBci(elements, viewport)`: `Σ (visibleArea/viewportArea) × (blurPx/20)` over elements whose computed `::before` (or host, to catch violations) `backdrop-filter` ≠ `none`; `visibleArea` = border box ∩ viewport ∩ every clipping ancestor; blur from the first `blur(<n>px)` in the value (a `url(#ag-lens-…)` lens with no blur counts 1.0 × area for BCI). Unit cases: full-viewport 20 px = 1.0; full-viewport 12 px scrim = 0.6; 4.1 modal reconstruction (full 40 px overlay + 40 px panel 30% + inner surfaces) ≥ 2.4; half-offscreen element counts half; `none` = 0.
2. **PERF-037 `instrument.js`** (injected with `page.addInitScript` before any story script): wraps `requestAnimationFrame`/`cancelAnimationFrame` (pending set), `setInterval`/`clearInterval` (active set), `setTimeout` (pending count), `EventTarget.prototype.addEventListener`/`removeEventListener` on `window`/`document` (per type counts), `MutationObserver`/`ResizeObserver`/`IntersectionObserver` constructors + `disconnect` (live count), `HTMLCanvasElement.prototype.getContext` for `webgl`/`webgl2` (live contexts, released on `WEBGL_lose_context.loseContext()`); a rAF-timestamp frame probe (`window.__agPerf.frames`, used for WebKit/Gecko and devices); `PerformanceObserver` for `longtask`, `long-animation-frame` (with `scripts[].sourceURL`), `event` (durationThreshold 16) where supported. Exposes `window.__agPerf.snapshot()` returning: counters above, `document.getAnimations()` with `iterations === Infinity` (target, properties), blurred-element list (selector, `::before` + host `backdrop-filter`, rect, effective nesting = count of ancestors with non-`none` `::before` backdrop-filter), `computeBci`, active `svg filter` ids, `svg[data-ag-lens-defs]` count, `will-change` ≠ `auto` element count. Snapshot fails loudly (throws) if called before `instrument.js` initialised.
3. **PERF-038 `perf-results.schema.json`** (JSON Schema 2020-12): `{ sha, runnerInstanceType, browser {name, version}, gpu {compositing, rasterization} (profile a), profile ∈ a60|a120|b|c|d-webkit|d-gecko, records[] }`; each record `{ subject, storyId, tier, pointer, scene, viewport, interaction, metrics {frameP50, frameP95, frameP99, droppedFrames, layoutCount, layoutMs, recalcCount, recalcMs, paintMs, compositeMs, rasterMs, gpuTaskMs, longTasks {count,totalMs,maxMs}, loaf {count, over100, blockingMs, libraryAttributed}, inpP95, layers, blurred, maxNesting, maxBlurPx, bci, svgFilters, webglContexts, heapMb, heapDelta10Mb, settled {raf, intervals, infinite}}, deltaVsBlank {frameP95, longTasksTotalMs} }`. Every metric is `required`; engines that cannot provide one (WebKit/Gecko LoAF, CDP metrics) carry `{ "unsupported": "<engine>" }` objects, which the schema allows **only** for the profile-(d) metric list in PRD §4.6(d).
4. **PERF-039 `run-perf.mjs` core.** Node ESM, `@playwright/test`'s `chromium`/`webkit`/`firefox` launchers. Exit 2 with stderr `remote-only` unless `AG_REMOTE_RUNNER=1`. Inputs: `--storybook <dir>` (served by a static server bound to 127.0.0.1), `--profiles`, `--subjects <budgets.json>`, `--out <dir>`. Per (subject × viewport × tier × scene): open `iframe.html?id=<storyId>&globals=environment:<scene>;certify:1;tier:<tier>;pointer:<p>;reducedMotion:<m>`, wait for `document.fonts.ready` + 2 rAF, run the scripted interaction for 5 s (`scroll` = 3 wheel sweeps top→bottom→top; `hover` = pointer path over every `[data-ag-surface]`; `open-close` = activate every `[data-ag-trigger]`/`[aria-haspopup]` 3×; `type` = 40 chars into the first textbox), with CDP `Tracing.start` categories `devtools.timeline,disabled-by-default-devtools.timeline.frame,blink.user_timing,gpu,viz` and `Performance.getMetrics` before/after. Frame times from `PipelineReporter`/`DrawFrame` events; layer count from `LayerTree.layerPainted`/`compositingReasons` snapshot; heap from `Runtime.getHeapUsage` after 10 mount/unmount cycles of the story (remount via Storybook `forceReRender` channel event) with `HeapProfiler.collectGarbage`. Settle = 500 ms with no `transitionrun`/`animationstart` events, then `__agPerf.snapshot()`. Fail closed (non-zero exit, record `error`) on: page error, story render error, 0 frames, missing metric, scene load failure, story id absent from `index.json`, or `parameters.perf` missing (PERF-050). Validate output against the schema before writing `perf-results.json`.
5. **PERF-040 Profiles.** (a) headed Chromium on the GPU worker, `--force-device-scale-factor=2`, `--enable-gpu-rasterization`, virtual X display at 60 Hz and at 120 Hz (set the mode with `xrandr` on the worker; the harness measures the vsync interval from `DrawFrame` spacing on the blank story and fails if it is >5% off target), vsync on (never `--disable-gpu-vsync`); read `chrome://gpu` and fail if `Compositing` or `Rasterization` report `Software`. (b) Chromium 390×844, DPR 3, `hasTouch`, `isMobile`, `Emulation.setEmulatedMedia` `pointer: coarse`/`hover: none`, `Emulation.setCPUThrottlingRate {rate: 4}`. (c) `chrome-headless-shell` on the r7i class used in `runtime-remote.md` (record exact instance type and Chromium version; 4.1 used 141.0.7390.37). (d) Playwright WebKit and Firefox: rAF probe and DOM counts only; LoAF/longtask/CDP fields `unsupported`.
6. **PERF-041 Baseline subtraction (REQ-PERF-33).** Every run measures `perf-harness-blank--default` per profile first; each record gets `deltaVsBlank`. Grades use absolute frame time and delta long tasks.
7. **PERF-050 Story metadata contract.** Read `parameters.perf` (`{ budget: { surfaces, bci }, interaction }`) from the preview (`__STORYBOOK_PREVIEW__.storyStore`); a subject story without it fails the run with `missing parameters.perf: <storyId>`.
8. **PERF-048 Label read-back.** After load, read `document.documentElement.dataset.agTier`, `matchMedia('(pointer: coarse)').matches`, `matchMedia('(prefers-reduced-motion: reduce)').matches`, and the scene id the preview reports; any mismatch with the requested cell fails `label-mismatch` (REQ-QA-17 pattern; no story derives tier heuristically, §13.4).
