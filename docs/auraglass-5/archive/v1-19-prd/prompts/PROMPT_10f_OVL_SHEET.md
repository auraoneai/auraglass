## 4. Steps
1. **OVL-097 Parts and sides (REQ-OVL-30).**
   - Built on Base UI Dialog.
   - `side: "start"|"end"|"top"|"bottom"|"left"|"right"` (default `"end"`). `start`/`end` resolve via `dir` (RTL flip); `left`/`right` never flip.
   - `modal = true`; `open`/`defaultOpen`/`onOpenChange` as in Dialog (`OverlayOpenChangeDetails`).
   - Register `useOverlayLayer({ kind: "sheet", modal })`.
2. **OVL-098 Action preset (REQ-OVL-31).** `preset: "panel"|"action"`. `action` forces `side="bottom"` and renders `Sheet.Action` items (`<button>`) plus a separated cancel `Sheet.Close`. It is not a new export.
3. **OVL-099 `useSheetDetents.ts` (REQ-OVL-32).**
   - Pure function `resolveDetent({ positionPx, velocityPxMs, detentsPx, viewportPx }) → { index } | { close: true }`.
   - The velocity threshold is 0.5 px/ms. A downward fling past the lowest detent closes the sheet.
   - `detents?: Array<number|"content"|"full">` (default `["content"]`), as fractions of `100dvh`. Controlled/uncontrolled `detent`/`defaultDetent`/`onDetentChange(index)`.
4. **OVL-100 `SheetHandle.client.tsx` drag (REQ-OVL-32/-39).**
   - Use pointer events on the handle only, with `touch-action: none` on the handle and pointer capture.
   - Write `transform: translateY()` to the popup ref inside rAF. There are no React state updates per `pointermove`.
   - On release, snap with a CSS `linear()` transition, or the `aura-glass/motion` spring when it's installed. No layout properties are animated.
   - Under RTL, a `side="left"` sheet mirrors its drag direction.
5. **OVL-101 Handle a11y (REQ-OVL-33).**
   - The handle is a `<button aria-label={labels.handle ?? "Resize sheet"}>`. Enter/Space cycles detents upward and Escape closes.
   - Each detent change announces through the provider announcer: `labels.detents?.[i]`, defaulting to "Half height" or "Full height".
   - Body stays scrollable and focusable at every detent.
   - The handle hit area is ≥44×44 under coarse pointers.
6. **OVL-102 Full-height (REQ-OVL-34).** The popup sets `data-ag-full-height` when the active detent is `"full"`, or when a side sheet's block size is ≥90% of the viewport (measured with a ResizeObserver ref callback that has cleanup). The resolved fill comes from PRD-MAT CSS (`tinted`).
7. **OVL-103 `Sheet.css` (REQ-OVL-35/-36/-38).**
   - Safe areas:
     - Bottom sheets pad `env(safe-area-inset-bottom)`.
     - Side sheets pad the outer edge's left/right inset.
     - Top sheets pad `env(safe-area-inset-top)`.
   - Side sheet size `sm|md|lg` = 320/400/560px, capped at `calc(100vw - 48px)`. Below a 640px container they go full width and the Handle is hidden.
   - Bottom/top sheets are max 640px wide and centred at ≥640px. Their block size has a max of `calc(100dvh - env(safe-area-inset-top) - 8px)`.
   - Material is `overlayMaterial("sheet")` (thick). There is no sheet-specific blur or radius.
   - Motion is a `translate` along the side using `--ag-duration-medium`. The `"full"` detent uses `--ag-duration-large`. Calm mode is opacity only.
8. **OVL-104 Non-modal (REQ-OVL-37).** `modal={false}` renders no scrim, applies no inert and no scroll lock. Focus moves in on open and returns on close, and Tab can leave the sheet.
9. **OVL-105 `Sheet.meta.ts`.**
   - Thickness `thick`, `budgetKb: 24`, blurred layers 2 (modal) / 1 (non-modal).
   - APG: dialog-modal.
   - Lineage: `GlassDrawer`, `GlassBottomSheet`, `GlassActionSheet`, `LiquidGlassAdaptiveSheet`, `MobileGlassBottomSheet` (pointer only), and `GlassMobileNav`'s drawer behaviour.
   - `migration`: `position`/`placement` → `side`, snap props → `detents`, `actions[]` → `preset="action"` + `Sheet.Action`.
   - `selectorChanges`.
10. **OVL-106** Root exports (1 value + 2 types).
11. **OVL-107 `Sheet.test.tsx`.** Named cases:
    - "sides incl RTL flip"
    - "preset action"
    - "detent state machine": table-driven `resolveDetent` cases for slow drags near each detent, fast flings up and down, and a fling below the lowest detent → close
