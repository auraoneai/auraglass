## 4. Steps
1. **MAT-045 `resolveRole(role, sizeClass?)`** (REQ-MAT-03, 57, 74) is pure. Defaults: `layer` falls back to `chrome`. `variant` defaults to `regular`, and is omitted when `layer=content` with no explicit variant. `content` defaults to `content-raised` when `layer=content`. `shape` defaults to `fixed`. For `thickness`, an explicit value wins; otherwise `sizeClass` maps `control→thin, bar→regular, panel→regular, sheet→thick`; otherwise `regular`. When `refraction` is set, `data-ag-sizeclass` is the passed size class, or is derived (`thin→control, regular→bar, thick→panel`). Never emit refraction or sizeclass for `sheet`. `fallbackRadius` becomes `data-ag-radius=<token>`. It is not exported from `index.ts`.
2. **MAT-046 `materialProps(role)`** (REQ-MAT-02) returns `{ className:'ag-surface', 'data-ag-surface':'', 'data-ag-layer', … }`, with only the set or defaulted attributes, as boolean attributes `''` for `interactive|prominent|refraction|allow-nested`. It never returns a `style` key. It must not touch `window`, `document`, React or context; check this with a grep in MAT-064.
3. **MAT-047 `Surface`** (REQ-MAT-04, 05, 06, 12) renders a `<div>` by default. With `render`, it uses `cloneElement` so there is a single DOM node. `className` is merged with `clsx`. For non-`data-ag-*` attributes the consumer wins; for `data-ag-*` the role wins. `ref` is a prop, forwarded. `style` is passed by reference only when given, and is never merged. No hooks, context, effects, or `"use client"`.
4. **MAT-048 `SurfaceGroup`** (REQ-MAT-08): one element, `materialProps({layer:'chrome'})` plus `data-ag-group=''` and `data-ag-spacing=<SpaceToken>` (default `'2'`). Props are `spacing` and `children` only.
5. **MAT-049 `Environment`** (REQ-MAT-09, 82): `data-ag-backdrop={backdrop}`. `auto` combined with `image`/`video` becomes `media`. The media layer is `<img decoding="async" alt="" aria-hidden="true">` or `<video muted playsInline aria-hidden="true">`, placed behind the children. Autoplay policy belongs to MED; don't implement it here. No sampling.
6. **MAT-050 `ScrollEdge`** (REQ-MAT-10): props `edge: 'top'|'bottom'` and `edgeStyle: 'soft'|'hard'`. The prop is not `style`, which would collide with React's style attribute (SC-22, erratum E-01). It renders `<div aria-hidden="true" data-ag-part="scroll-edge" data-ag-edge data-ag-edge-style>` with defaults `top`/`soft`.
7. **MAT-051 `ConcentricFrame`** (REQ-MAT-11): `data-ag-radius=<RadiusToken>` and `data-ag-inset=<SpaceToken>`. No inline style.
8. **MAT-052 `useMaterialTier()`** (REQ-MAT-07): `"use client"`, built on `useSyncExternalStore`. The server snapshot is `'standard'`. It reads `document.documentElement.dataset.agTier`, accepting `lightweight|standard|enhanced` and mapping anything else to `'standard'`. One module-level `MutationObserver` (`attributeFilter:['data-ag-tier']`) is created on the first subscribe and disconnected when the last subscriber leaves.
9. **MAT-053 entries** (REQ-MAT-01, 60): `src/material/index.ts` exports exactly the 8 values `Surface, SurfaceGroup, Environment, ScrollEdge, ConcentricFrame, materialProps, defineMaterial, useMaterialTier` plus the 11 types, with no directive on the barrel. `resolveRole` and `LensDefs` are not exported. No material module emits `data-ag-material` (D-20). Nothing under `src/material/**` contains WebGL, `three` or `<canvas>`.
10. **MAT-054 `dev/warnings.ts`** (REQ-MAT-24, 45, 51): `warnOnce(key, message)` uses a `WeakSet<Element>`, and every call site is guarded by `process.env.NODE_ENV !== 'production'`. Messages, exactly: `[aura-glass] allowNested at depth N at <selector>` (matches PERF's `/allowNested at depth \d/`); `[aura-glass] variant="clear" requires a declared backdrop; rendering as "regular"` (it walks to the nearest `[data-ag-backdrop]` and warns when that is `auto` or missing); and `[aura-glass] refraction is ignored on layer="<layer>"`.
11. **MAT-055 `dev/surfaceCounter.ts`** (REQ-MAT-52, 72, 74) is dev only. Export `startSurfaceCounter(root=document)` for A11Y's provider (A11Y-029) to call. It counts after mount and on `requestIdleCallback` after a debounced 500ms `MutationObserver`. It counts visible, viewport-intersecting elements whose `getComputedStyle(el,'::before').backdropFilter !== 'none'`. It warns once per threshold crossing: >6 at `(pointer:fine)`, >3 at `(pointer:coarse)`, >2 refracting, any refracting surface over 25% of the viewport area, blur >32px, full-viewport blur >12px, effective live-backdrop nesting depth >1, and any `allowNested` surface at depth ≥2 (PERF's accepted tightening request). It does not compute BCI. It never writes attributes or styles. Production builds must contain no `surfaceCounter` string (bundle check with MAT-044, and PERF REQ-PERF-08).
