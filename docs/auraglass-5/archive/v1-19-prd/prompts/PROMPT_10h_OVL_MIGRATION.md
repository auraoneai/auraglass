3. **OVL-133 Dialog-family adapters.**
   - `GlassModal`/`GlassDialog` map:
     - `open` + `onClose` → `onOpenChange` (`if (!o) onClose()`)
     - `title`/`description`/`footer` → parts
     - `role="alertdialog"` → `AlertDialog`
     - `size` → `Popup size`
     - `variant="drawer"` → `Sheet side="bottom"`; `variant="fullscreen"` → `size="full"`
     - `closeOnBackdropClick`/`closeOnOverlayClick` → `dismissible`
     - `closeOnEscape={false}` → filter `reason === "escape-key"`

   - `isContained` renders `Surface` with a dev warning (REQ-OVL-24).
4. **OVL-134 Sheet-family adapters.** `position` → `side`; snap props → `detents`; `actions[]` → `preset="action"` + `Sheet.Action`.
5. **OVL-135 Popover/Tooltip adapters.**

   - `trigger="hover"` and `GlassHoverCard` → `openOnHover`.

   - `Positioner`/`GlassPositioner` → an adapter with `Popover.Positioner` semantics and a dev warning (REQ-OVL-45).
6. **OVL-136 Menu adapters.**

   - `LiquidGlassPopoverMenu` → `Menu`.
7. **OVL-137 Toast adapters.**
