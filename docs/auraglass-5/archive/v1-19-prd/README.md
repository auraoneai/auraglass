# AuraGlass 5.0 program documents

Planning set for the AuraGlass 4.1.0 → 5.0 program (baseline `aura-glass` 4.1.0 at `15b6de6f7`, 2026-10-06). Start with the [master PRD](AURAGLASS_5_MASTER_PRD.md). Decisions live in the [target architecture](AURAGLASS_5_TARGET_ARCHITECTURE.md), and names, paths and owners live in the [shared contract registry](prd/_shared-contracts.md). Where documents disagree, the registry wins over a PRD, and the architecture wins over everything else except the registry's errata (§J).

## Deliverables A–L

Letters follow the program brief: A executive assessment, B scorecard, C competitive gap analysis, D technical autopsy, E component inventory and disposition, F missing-capability map, G target architecture, H PRD suite, I agent execution prompts, J file-level task ledger, K migration strategy, L certification plan. Completeness against the brief is recorded in [`prd/_completeness-review.md`](prd/_completeness-review.md).
