# Liquid Glass Documentation

This is the dedicated home for AuraGlass Liquid Glass documentation. Use it for material rules, migration guidance, primitive APIs, the release showcase, and the map from existing glass components to newer Liquid Glass patterns.

Component API pages live in the [component reference](https://auraglass-48859d.gitlab.io/components/button) of the docs site, generated from each 5.0 component's meta.

## Start Here

- [Design rules](./design-rules.md): when to use Liquid Glass, when to avoid it, and how to keep it accessible.
- [Component map](./component-map.md): which Liquid Glass component to choose instead of scanning every export.
- [Migration guide](https://auraglass-48859d.gitlab.io/plat/migrate/5): how existing glass surfaces move to 5.0.
- [Showcase](./showcase.md): the public 3.0 Liquid Glass showcase reference.
