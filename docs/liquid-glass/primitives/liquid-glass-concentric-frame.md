# ConcentricFrame

`ConcentricFrame` from `aura-glass/material` standardizes nested corner geometry. Use it when controls sit inside sheets, toolbars, sidebars, cards, or media control groups. (The 4.x `LiquidGlassConcentricFrame` name survives only as a deprecated adapter in `aura-glass/compat`.)

It exposes CSS variables for parent radius, inset, and computed child radius so children can align with the surrounding material shape.
