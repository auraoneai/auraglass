# ScrollEdge

`ScrollEdge` from `aura-glass/material` marks the boundary where floating material UI overlaps scrollable content. (The 4.x `LiquidGlassScrollEdge` name survives only as a deprecated adapter in `aura-glass/compat`.)

Use `soft` for fluid mobile and media surfaces. Use `hard` for dense tables, inspectors, and desktop toolbars. The edge is pointer-event transparent and should not be used as decoration when there is no overlapping scroll content.
